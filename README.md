## 📌 Domain Overview
This repository contains a full QA engineering portfolio spanning formal test case design, structured defect management, and browser-driven end-to-end automated testing.

---

## 🚀 Projects & Deliverables

### 1. Manual Test Case Suite (Zephyr Scale / TestRail)
* **Tool:** TestRail / Zephyr Scale
* **Project Scope:** Designed a 50+ enterprise test case matrix covering critical web application functionality.
* **Key Implementation:**
  * Developed positive, negative, boundary value, and equivalence partitioning test suites.
  * Specified preconditions, reproduction steps, test data, and expected outcomes.
  * Segmented test suites across Smoke, Sanity, Regression, and Acceptance passes.

### 2. Defect Lifecycle Management (Jira)
* **Tool:** Jira Software
* **Project Scope:** Standardized the logging, triaging, and tracking of software defects through to resolution.
* **Key Implementation:**
  * Authored structured bug tickets with severity/priority ratings, environment details, and visual evidence.
  * Managed bug workflow lifecycles (`Open` ➔ `In Progress` ➔ `Ready for QA` ➔ `Verified Closed`).

### 3. Web UI Automation Framework (Playwright)
* **Tool:** Playwright (TypeScript / JavaScript)
* **Project Scope:** Automated an end-to-end checkout flow for an E-commerce web platform.
* **Key Implementation:**
  * Architected a modular Page Object Model (POM) to maximize test maintainability and code reuse.
  * Automated user authentication, dynamic catalog search, cart verification, and mock checkout.
  * Configured multi-browser parallel execution (Chromium, Firefox, WebKit) and rich HTML execution reports.
